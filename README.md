# Jorge Nicolau — Personal Website (Modern Design)

This repository contains a modern, responsive personal website and accompanying online resume page. The design features a premium aesthetic utilizing a responsive sidebar layout, dual themes (light/dark mode), and structured typographic components.

## Key Features

- **Responsive Fixed Sidebar**: Desktop sticky sidebar layout on the left that transitions into a compact, responsive header and menu on mobile screens.
- **Theme Toggling**: Seamless light & dark mode theme support using CSS custom variables and an interactive toggler, persisting preference via `localStorage`.
- **Modern Typography**: Uses Google Fonts' `Outfit` for geometric headings and `Inter` for highly readable body text.
- **Interactive Timelines**: Structured vertical timelines for Professional Experience and Education history.
- **Visual Skills & Expertise Grid**: Categorized tech stack groups formatted into elegant, wrapping tag badges.
- **Language Proficiency Cards**: Organized grid display with distinct CEFR proficiency indicators (C2, B2, B1).
- **Zero Heavy Frameworks**: Handcrafted with lightweight, vanilla HTML5, CSS3, and high-performance vanilla JavaScript.

## Contents

- `index.html` — Personal homepage containing the main introduction and bio.
- `resume.html` — Detailed CV containing interactive experience timelines, education, languages, and technical skills.
- `styles/styles.css` — Custom stylesheet defining CSS variables, layouts, and animations.
- `images/` — Avatar and favicon image assets.
- `CNAME` — Custom domain routing configuration.
